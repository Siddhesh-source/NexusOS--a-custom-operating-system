Welcome to the BharatOS Browser

This browser is written from scratch inside BharatOS. Pages come over the BharatOS network stack (its own TCP/IP, written in C), or from files on this machine.

Try these

  • example.com - a real page from the internet (over plain HTTP)
  • neverssl.com - another site that still speaks plain HTTP
  • your own PC - run python -m http.server 8000 on your PC first
  • How BharatOS works - a page stored inside BharatOS

Keys

  • Ctrl+L, or click the address bar: type an address, then Enter
  • Up, Down, Page Up, Page Down, Space: scroll
  • Backspace or the Back button: the page before

What it cannot do yet

Secure (https) sites need encryption (TLS), which comes later. Pictures, styles and scripts are not shown: you get the words and the links.
