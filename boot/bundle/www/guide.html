How BharatOS works

BharatOS is a whole operating system written from scratch: no Linux, no borrowed kernel. Everything you see on this desktop is drawn by it.

The parts

  • Memory: a buddy allocator for pages, slab caches for small objects, and copy-on-write.
  • Threads: a scheduler with one queue per CPU that steals work when a CPU is idle.
  • Safety: a lock-order checker, guard pages, and crash reports with function names.
  • Files: folders and files in memory, filled at boot from a bundle on the disk.
  • Network: its own driver for the Intel e1000 card, plus ARP, IP, ICMP, UDP, DNS, TCP and HTTP.
  • Desktop: windows, a dock, and the apps: Terminal, Files, Code, Browser, Player, Monitor, Health.

Checks itself

Every boot runs hundreds of self-checks inside the kernel. The Health app shows the result. Type checks in the Terminal to run them again.

  boot  ->  self-checks  ->  login  ->  desktop
             (hundreds)       (your name)
